### Cards

```css
.card-product {
  background: #FFFFFF;
  border: 1px solid rgba(0, 0, 0, 0.07);
  border-radius: 16px;
  box-shadow: var(--shadow-card);
  transition: box-shadow 300ms;
}
.card-product:hover { box-shadow: var(--shadow-card-hover); }
```

The image well is always 4:5 (`aspect-[4/5]`), radius 12px, with a 700ms
`scale-105` image zoom on hover and a touch-press equivalent (a tap has no
hover, so the press pins the lift until the next press elsewhere).

The card title is a real link stretched over the card with
`after:absolute after:inset-0`; floating controls (wishlist heart, add
button) sit above it at `z-10`.

### Buttons

```css
.btn-pill-primary {
  background: #121212; color: #fff; border-radius: 999px;
  padding: 14px 28px;
  font: 700 12px/1 "Space Grotesk";
  letter-spacing: .16em; text-transform: uppercase;
  transition: background 200ms;
}
.btn-pill-primary:hover { background: #F45B50; }
```

### Modals

Overlay `rgba(18,18,18,.6)` + `backdrop-blur-md`; panel radius 24px (16px for
the size guide); Escape closes, scrim click closes, page scroll locks.

### Countdown (the vault clock)

`components/drops/vapor-countdown.tsx` — canvas grain field, digits
sublimate on change, `<time>` carries the machine-readable value,
`prefers-reduced-motion` draws static digits. Target is the real
UTC-midnight deadline (`secondsToVaultClose()` in `lib/drop.ts`).

## Style Guidelines

**Style:** Exaggerated Minimalism

**Keywords:** Bold minimalism, oversized typography, high contrast, negative
space, loud minimal, statement design

**Best For:** Fashion, architecture, portfolios, agency landing pages,
luxury brands, editorial

**Key Effects:** oversized type, weight 700–900, tight tracking (-0.02em),
generous whitespace, one focal CTA per section

### Page Pattern

**Pattern Name:** Minimal Single Column

- **Conversion Strategy:** Single CTA focus. Large typography. Lots of
  whitespace. No nav clutter. Mobile-first.
- **CTA Placement:** Center, large CTA button
- **Section Order:** 1. Hero headline, 2. Short description, 3. Benefit
  bullets (3 max), 4. CTA, 5. Footer

## Anti-Patterns (Do NOT Use)

- ❌ Boring design
- ❌ Hidden work

### Additional Forbidden Patterns

- ❌ **Emojis as icons** — use Material Symbols
- ❌ **Missing cursor:pointer** — all clickable elements must have it
- ❌ **Layout-shifting hovers** — no scale/translate on non-image elements
- ❌ **Low contrast text** — maintain 4.5:1 minimum contrast ratio
- ❌ **Instant state changes** — always use transitions (150–300ms)
- ❌ **Invisible focus states** — focus states must be visible for a11y
- ❌ **Fake controls** — a button that does nothing is worse than no button
- ❌ **Hardcoded catalog data** — prices, stock and names come from the API

## Pre-Delivery Checklist

Before delivering any UI code, verify:

- [x] No emojis used as icons
- [x] All icons from one consistent set (Material Symbols)
- [x] `cursor-pointer` on all clickable elements
- [x] Hover states with smooth transitions (150–300ms)
- [x] Text contrast 4.5:1 minimum
- [x] Focus states visible for keyboard navigation
- [x] `prefers-reduced-motion` respected
- [x] Responsive: 375px, 768px, 1024px, 1440px — no horizontal scroll
- [x] No content hidden behind fixed navbars
- [x] One alignment column site-wide (`.shell`)
- [x] No dead controls, no hardcoded catalog data
